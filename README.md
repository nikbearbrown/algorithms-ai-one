# Algorithms (AI Plus One)

## About the book

A compact rough draft for readers who can write a small program and follow contradiction or induction. You will specify what an algorithm promises, justify that promise, and distinguish a complexity result from a benchmark on a particular machine. Python 3.10 or newer is optional for the offline implementation track.

## Start reading

Start with [Write the contract and count the work](chapters/01-contract.md). Use the [complete chapter guide](#chapter-guide) to find every chapter in reading order.

## Chapter guide

### Part 1 · Specify and prove

1. [Write the contract and count the work](chapters/01-contract.md): Write input and output conditions and count the operations that matter.
2. [Represent reachability and cost](chapters/02-reachability.md): Choose a graph representation and compare reachability with minimum cost.
3. [Earn the greedy choice](chapters/03-greedy.md): Identify when a greedy choice is safe and produce a counterexample when it is not.
4. [Combine solutions across subproblems](chapters/04-subproblems.md): Define the subproblems and justify the recurrence that combines them.

### Part 2 · Diagnose limits

5. [Explain why a choice is hard](chapters/05-hardness.md): Separate evidence of computational hardness from a slow implementation.
6. [Benchmark what the proof does not predict](chapters/06-benchmark.md): Measure time and frontier size and reconcile observed results with the proof.

## How to teach or study it

Start with the contract, then prove what a search or optimization step preserves. Work a small counterexample before reading the proof. After the complexity and measurement chapters, use the [unaided capstone](practice/capstone.md) to recommend an algorithm for a constrained exchange and defend it with both an argument and a test. A frontier size counts items, not bytes; the benchmark does not measure process resident memory.
